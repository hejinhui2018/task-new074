# 织物组织设计台（Weave Design Bench）

一个在方格纸上设计多综织物的交互式工作台。设计师调整**穿综**、**提综（综框×踏板连接）**或**踏纹**时，最终布面的**组织图**即时沿完整关系重算；超过允许长度的**经 / 纬浮线**会标出方向、位置和长度，点击问题即可定位到相关穿综或踏纹；还可以**逐纬试织预演**，播放途中做的修改会从当前行起立即生效。

使用 **React 18 + TypeScript + Vite** 构建，核心计算为纯函数，数据保存在浏览器 `localStorage`，可一键恢复内置样稿。

## 内置样稿：8 综破斜纹

打开即载入 **8 综 / 8 踏板 / 32 根经纱 / 24 行纬纱** 的破斜纹（broken twill）：

- **穿综**：断穿法 `1-4, 8-5`（斜纹线在中段断开反向），循环长度 8；
- **踏纹**：顺踏 `1-8`，循环长度 8；
- **连接（提综）**：每个踏板提起相邻 4 片综，即 4/4 斜纹；
- 成品布面为人字棱纹，经、纬最长浮线恰为 **4** 格，默认阈值即 4，因此初始状态无报警；把“最大浮线”调成 3 即可看到全部问题被标出。

## 四图联动

界面按传统织纹排版严格对齐：

```
            [踏板序号]
[综框序号]  连接矩阵(H×T)   穿综图(H×W)
            踏纹图(R×T)     组织图(R×W)
[纬纱序号]
```

- **穿综图**：每列一根经纱，综钉表示它穿入哪片综。点击格点、或按住鼠标扫过，即可把经纱改穿到该综框。
- **连接矩阵（提综）**：行＝综框（第 8 综在顶），列＝踏板；黑格表示踩下该踏板时提起该综。点击切换。
- **踏纹序列**：每行一根纬纱，方块表示所踩踏板；同样支持点击 / 拖拽涂画。
- **组织图**：自动计算，每格颜色＝在上的纱线（经纱颜色＝经浮点，纬纱颜色＝纬浮点）。

穿综、踏纹都按各自的**循环长度**周期铺满整幅布（粗线为循环接缝），改一个循环位会作用到所有重复的经列 / 纬行。任意格点的修改都会触发整幅组织图重算：

```
W[r][c] = tieUp[ threading[c] ][ treadling[r] ]
          1 = 经浮点（经在上）   0 = 纬浮点（纬在上）
```

## 浮线检测与定位

- **经浮线 ↕**：一根经纱在某几行连续被提起（列向连续的经浮点 `1`）。
- **纬浮线 ↔**：一根纬纱在某几列连续压过经纱（行向连续的纬浮点 `0`）。

检测会把穿综 / 踏纹的周期铺贴考虑在内，**跨越组织图首尾接缝**的连续浮线也会合并并标出（问题列表里标注“跨循环接缝”）。红框＋徽标（`↕4` / `↔5`）给出方向与长度；长度**严格大于**“最大浮线”设置才报警。

点击组织图中的浮线或右侧问题列表，即可定位成因：

- 蓝框：相关的穿综列与踏纹行；
- 连接矩阵**红格**：导致经浮线的“提起”连接（断开可消除经浮线）；
- 连接矩阵**琥珀格**：纬浮线“应提未提”的空位（补上连接可消除纬浮线），点击即可直接修改。

## 逐纬试织预演

- 播放 / 暂停、上一纬 / 下一纬、回到起点、速度可调；
- 播放时按踏纹顺序一行行生成布面，组织图中已织行全饱和、未织行淡化、下一纬行以琥珀色描边标出；
- **播放途中编辑任何格点，下一行起立即采用最新组织**——实现上组织矩阵每次渲染都对最新状态整体重算，播放进度只是对结果取前缀（`previewRows(state, revealedRows)`），因此“从当前行继续”天然使用最新数据，无需重放。

## 数据与恢复

所有修改自动保存到浏览器本地（键 `weave-design-bench:v1`），刷新或重开页面后恢复。设置面板的**「恢复内置样稿」**会丢弃当前设计并重置播放进度。本地数据在读取时做结构校验与补全，损坏或字段越界时安全回退到内置样稿。

可在设置区调整：综框数、踏板数、经纱 / 纬纱根数、穿综 / 踏纹循环长度、最大浮线长度、经 / 纬纱颜色。

## 目录结构

```
src/
├─ lib/                 # 与 UI 无关的纯领域逻辑（全部有单元测试）
│  ├─ types.ts          # 数据模型
│  ├─ defaultDraft.ts   # 8 综破斜纹内置样稿
│  ├─ repeat.ts         # 循环展开 / 长度调整
│  ├─ weave.ts          # 组织矩阵 computeWeave、逐纬 previewRows
│  ├─ floats.ts         # 经/纬浮线检测（含跨接缝）与成因定位
│  ├─ edits.ts          # 格点编辑、规格 / 循环尺寸变更
│  └─ storage.ts        # localStorage 读写、校验与回退
├─ state/useDraft.ts    # React 状态：编辑、重算、浮线、播放、持久化
├─ components/          # Board / Controls / FloatPanel
└─ App.tsx
```

## 测试覆盖

56 个测试（Vitest；纯逻辑用 node 环境，组件用 happy-dom + Testing Library）：

- **组织矩阵计算**：`W[r][c] = tieUp[threading[c]][treadling[r]]`、全上 / 全下边界、连接点修改影响面、内置样稿人字结构逐格断言；
- **循环展开**：周期取模铺满、循环长度增减（截断 / 按旧周期补齐）、尺寸变更时夹紧与连接矩阵重采样；
- **浮线检测**：经 / 纬方向、长度等于上限不报警、跨首尾接缝合并、整行同值不重复计数、空矩阵、问题到穿综 / 踏纹的定位映射；
- **编辑后预演同步**：织到中途改连接 / 穿综 / 踏纹后，后续行立即等于最新整幅组织的前缀；
- **存储恢复**：合法数据保留、损坏回退、缺字段补全、越界值修正；
- **App 集成冒烟**：四联图渲染、改阈值→问题出现→点击定位、格点编辑重算、逐纬推进 / 回退、播放中编辑、持久化、恢复样稿。
